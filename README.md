# Landing Page — Fertilizantes

Landing page institucional em React + Vite, baseada no conceito visual apresentado.

## Rodar

```bash
npm install
npm run dev
```

Depois abra o endereço informado pelo Vite.

## Antes de apresentar ao cliente

1. Troque "NUTRI SOLO" pelo nome real da empresa.
2. Troque o número em `src/main.jsx` na constante `WHATSAPP`.
3. Ajuste os textos das linhas Orgânica e Organomineral conforme os produtos reais.
4. Substitua as imagens do Unsplash pelas fotos reais da empresa quando disponíveis.
5. Adicione logo real da empresa se existir.

## Estrutura

- Hero institucional
- Sobre / propósito
- Linha Orgânica
- Linha Organomineral
- Benefícios
- Diferenciais
- CTA para WhatsApp
- Footer
- Layout responsivo para celular
